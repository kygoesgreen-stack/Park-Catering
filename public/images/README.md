# Image Assets

Place your images here with the filenames defined in `src/config/content.ts`.

## Required images by section:

### Hero
- `hero-background.jpg` — Full-bleed hero background (recommended: 1920×1080 landscape)
- `hero-poster.jpg` — Video poster frame fallback

### Story
- `story-family-kitchen.jpg` — Striking image of the Park family or kitchen (4:5 portrait)

### Services (3 cards)
- `service-firefighters.jpg` — Firefighters receiving a meal / field catering (3:4 portrait)

- `service-corporate.jpg` — Corporate or private event setup (3:4 portrait)

### Menu (4 categories)

## Image specs:
- Format: JPG (optimized), WebP supported
- Quality: 80-85% for photos
- All images should be high-quality, editorial photography
- Avoid: clip art, generic stock photos, anything that feels "clipping mask"
- Prefer: real food photography, authentic event moments, Montana landscapes
